# What to read for what — ForgeLM prerequisite study

Order roughly matches the build order. Est. total ~35-45h spread over the build.

## Block A — Foundations (before Day 1-2, ~6-8h)
- PyTorch 60-min blitz: tensors, autograd, nn.Module, optimizers, AMP
  https://pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html
- 3Blue1Brown — Neural Networks + Attention chapters (math floor: softmax, cross-entropy, matrix shapes, log-prob)
  https://www.3blue1brown.com/lessons/neural-networks
  https://www.3blue1brown.com/lessons/attention
- Pydantic v2 basics (data contract, Day 1)
  https://docs.pydantic.dev/latest/

## Block B — Language models (Days 2-3, ~8-10h)
- Sennrich et al. 2016 "Neural Machine Translation of Rare Words with Subword Units" (BPE, sec 2-3)
  https://arxiv.org/abs/1508.07909
- Karpathy nanoGPT — read model.py + train.py annotated
  https://github.com/karpathy/nanoGPT
- Vaswani et al. 2017 "Attention Is All You Need" — sec 3 only
  https://arxiv.org/abs/1706.03762
- Karpathy "Let's build GPT" video (2h, optional but high value)
  https://www.youtube.com/watch?v=kCc8FmEb1nY
- Optional: RMSNorm (arxiv 1910.07467), SwiGLU (LLaMA paper sec 2)

## Block C — Training (Days 4-5, ~6-8h)
- AdamW — Loshchilov & Hutter 2019
  https://arxiv.org/abs/1711.05101
- Cosine LR schedule + warmup — HF get_cosine_schedule_with_warmup docs
  https://huggingface.co/docs/transformers/en/main_classes/optimizer_schedules
- Gradient accumulation, mixed precision (torch.amp docs), reproducibility/seeds
  https://pytorch.org/docs/stable/amp.html
- HF datasets streaming API (TinyStories ingestion)
  https://huggingface.co/docs/datasets/stream

## Block D — Eval + inference (Days 6-7, ~6-8h)
- Perplexity & bits-per-byte math
  https://huggingface.co/docs/transformers/perplexity
- Sampling: greedy, top-k, temperature (HF generation docs, skim concepts)
- KV-cache — pharath nanoGPT blog
  https://pharath.github.io/posts/nanoGPT/
- torch.compile docs
  https://pytorch.org/docs/stable/generated/torch.compile.html

## Block E — Fine-tuning (Days 8-9, ~6h)
- Hu et al. 2021 "LoRA: Low-Rank Adaptation" — sec 3-4
  https://arxiv.org/abs/2106.09685
- Dettmers et al. 2023 "QLoRA" — sec 2-3 (NF4, double quant)
  https://arxiv.org/abs/2305.14314
- peft LoraConfig docs (concept only — we hand-roll)
  https://huggingface.co/docs/peft/conceptual_guides/lora

## Block F — Serving/MLOps (Days 10-12, ~6h)
- FastAPI basics + Pydantic response models
  https://fastapi.tiangolo.com/tutorial/
- Docker multi-stage builds (skim)
  https://docs.docker.com/build/building/multi-stage/
- OWASP API Security Top-10 (skim)
  https://owasp.org/API-Security/editions/2023/en/0x11-t10/
- HF Model Card guide
  https://huggingface.co/docs/hub/en/model-cards
- Google SRE book ch.3 — SLO/error budget (skim)
  https://sre.google/sre-book/service-level-objectives/
- ONNX export + ONNX Runtime quantization (Day 10, skim)
  https://onnxruntime.ai/docs/performance/model-optimizations/quantization.html
